# Glossary

## Agent

An ERC-8004 identity registered on a network: name, owner, feedback count, reputation score, and status. The id is the explorer row id for the fixture roster.

## Status

Where an agent sits in the reputation view. `active` has recent feedback, `quiet` has little activity, `unreviewed` has no score yet.

## Network

A chain the explorer can filter on. The code (`BASE`) is the id. The symbol and color are only for the mark next to the name.

## Average score

The mean of known reputation scores in the current view. Agents without a score do not count.

## Summary

The status counts and the average score for the agents in view.

## Roster

The agent table for the same view, newest registration first. The overview shows the three newest rows. The agents page shows every row, and the URL decides which row is open.
